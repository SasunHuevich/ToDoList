# ToDoList Plugin for Obsidian

Автоматическая сортировка ваших чек-листов в Obsidian. Плагин собирает все незавершённые и завершённые задачи в отдельные разделы, чтобы ваш список дел всегда был в порядке.

## 🚀 Возможности

- **Автоматическая сортировка**: задачи с `- [ ]` и `* [ ]` попадают в раздел `### Open`, а с `- [x]` / `- [X]` / `* [x]` / `* [X]` — в раздел `### Completed`.
- **Работает автоматически**: при каждом сохранении файла плагин проверяет, есть ли в нём маркер `%% ToDoList %%`, и если есть — приводит структуру в порядок.
- **Сохраняет остальной текст**: весь текст, не являющийся задачами, остаётся на своих местах (в начале файла).

## 📥 Установка

### Через сообщество Obsidian (после публикации)
1. Откройте **Настройки** → **Сообщество плагинов**.
2. Нажмите **Обзор** и найдите **ToDoList**.
3. Установите и активируйте плагин.

### Вручную (до публикации)
1. Скачайте файлы плагина.
2. Поместите папку с плагином в `<ваше хранилище>/.obsidian/plugins/`.
3. Перезагрузите Obsidian и активируйте плагин в настройках.
